Chase connection

Progress and update settings

Pacioli uses your existing Firefox profile and its LastPass installation. Each run opens a separate Chase tab; other tabs stay open. Sign-in approvals happen directly in Firefox. The connection must be enabled by starting Firefox with the Pacioli Firefox launcher.

Exports use your normal Firefox download settings. If a Save As dialog appears, complete it in Firefox. Pacioli imports the QFX file from its own Chase tab; the original file remains in your download location. Firefox cookies, passkeys, and vault storage stay in Firefox.

Manual QFX import is also available.
